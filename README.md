
# Handwritten Character Recognition

## Project Description
This project uses Machine Learning to recognize handwritten digits from 0 to 9 using the MNIST dataset.

## Technologies Used
- Python
- TensorFlow
- Matplotlib
- NumPy

## Dataset
The MNIST dataset contains 60,000 training images and 10,000 testing images of handwritten digits.

## Model
A neural network was built using TensorFlow Keras to classify handwritten digits.

## Results
The model achieved approximately 97.45% test accuracy.

## How to Run
Open the project notebook in Google Colab and run the cells in order.
